# Защита рабочих станций с Kaspersky Security Center

Учебный проект по централизованной защите Windows. На изолированном стенде из двух виртуальных машин проверены подключение рабочей станции к серверу управления, удалённое развёртывание KES и доставка события обнаружения в KSC.

## Мой вклад в учебную практику

- Подключал рабочую станцию Windows 10 к Kaspersky Security Center (KSC) через Агент администрирования и удалённо устанавливал Kaspersky Endpoint Security (KES).
- Настраивал ограничения USB-накопителей с исключениями для устройств и пользователей и блокировку запуска Яндекс Браузера через «Контроль программ».
- Проверял защиту с помощью EICAR, просматривал отчёты и диагностировал потерю связи с Сервером администрирования.

## Подтверждено при повторной сборке

| Проверка | Результат |
| --- | --- |
| Подключение Агента | Станция синхронизировалась с KSC по TLS на TCP 13000 |
| Удалённая установка | KSC успешно доставил KES 12.12.0.522 через Агент на Windows 10 |
| Восстановление связи | Отключение виртуального кабеля прервало связь. После подключения Агент снова синхронизировался |
| Антивирусная проверка по требованию | KES обнаружил и удалил EICAR. Событие обнаружения получено в KSC |

Политики USB и блокировки браузера относятся к прежней практике. [Объём повторной проверки и наблюдения](docs/verification.md)
