# Проверки повторной сборки

Учебная сеть соединяет сервер KSC-SRV и рабочую станцию KES-CLT. Матрица фиксирует результаты повторной сборки, описанной в [схеме стенда](architecture.md).

| ID | Действие | Ожидаемый результат | Фактический результат |
| --- | --- | --- | --- |
| LINK-01 | Проверить TCP 13000 и запустить `klnagchk` | Агент соединяется по TLS и синхронизируется с KSC | Пройдено. TCP 13000 доступен, `Use SSL: 1`, одна успешная синхронизация, код выхода 0 |
| INST-01 | Запустить задачу установки KES из KSC через Агент | Задача успешна, на клиенте установлена версия из пакета KSC | Пройдено. KSC показал один успешный результат без ошибок и запроса перезагрузки. На клиенте установлена версия 12.12.0.522 |
| LINK-02 | Отключить виртуальный кабель KES-CLT и снова подключить | Порт недоступен во время сбоя. После подключения Агент синхронизируется | Пройдено. TCP-проверка дала True → False → True. Диагностика завершилась сообщением `Sending heartbeat...OK` и кодом 0 |
| AV-01 | Записать образец EICAR и прочитать его без запуска | Файловая защита реагирует при записи или чтении | Расхождение. Запись и чтение прошли, файл сохранился, события обнаружения в этом прогоне отсутствовали |
| AV-02 | Запустить проверку EICAR по требованию | KES обнаруживает образец и применяет действие, KSC получает событие | Пройдено. Локальный отчёт зафиксировал обнаружение и удаление `EICAR-Test-File`. Событие появилось в KSC. Отдельная сводка вирусной активности вернула 0 строк |

EICAR — стандартный безопасный тестовый объект. Все прогоны выполнялись внутри учебной ВМ. Детали и скриншоты приведены в [материалах проверок](../evidence/README.md). [Описание теста EICAR](https://www.eicar.org/download-anti-malware-testfile/)
