## IncidentDesk

Учебная лаборатория анализа журналов аутентификации. Загружает CSV, показывает предупреждения и подтверждающие записи, сохраняет выводы в браузере и выгружает отчёты.

**React · TypeScript · Vite · Web Worker**

[Открыть IncidentDesk](https://rompel2000.github.io/incidentdesk/) · [Исходный код](https://github.com/ROMPEL2000/incidentdesk)

## Phishlab

Интерактивный тренажёр распознавания фишинга: 10 ситуаций, выбор подозрительных элементов, разбор решений и повтор ошибок.

**React · TypeScript · Vite · Vitest**

[Открыть тренажёр](https://rompel2000.github.io/phishlab/) · [Исходный код](https://github.com/ROMPEL2000/phishlab)
